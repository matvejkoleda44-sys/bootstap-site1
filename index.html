Основные операторы

Операторы ветвления используются для выполнения разных действий в зависимости от результата проверки условия.

Конструкция Назначение Пример
if Выполняет блок команд, если условие истинно. if (x > 0)
if ... else Позволяет выбрать один из двух вариантов. if (...) ... else ...
else if Используется для последовательной проверки нескольких условий. else if (x == 0)
switch Выбирает действие в зависимости от значения выражения. switch (number)

Разбор конструкций

if проверяет условие. Если результат проверки равен true, выполняется соответствующий блок команд. 
if (age >= 18) {
    console.log("Доступ разрешён");
}

Конструкция if ... else позволяет выполнить один блок при истинном условии, а другой — при ложном. 
if (score >= 60) {
    console.log("Зачёт");
} else {
    console.log("Незачёт");
}

else if применяется, когда необходимо проверить несколько условий последовательно. 
if (x > 0) {
    console.log("Положительное");
} else if (x < 0) {
    console.log("Отрицательное");
} else {
    console.log("Ноль");
}

switch удобен, когда требуется выбрать один вариант из нескольких возможных значений. 
switch (day) {
    case 1:
        console.log("Понедельник");
        break;
    case 2:
        console.log("Вторник");
        break;
    default:
        console.log("Другой день");
}

Как работает ветвление

Ветвление позволяет программе выбирать дальнейшее действие. Благодаря этому один и тот же алгоритм может вести себя по-разному в зависимости от входных данных.

01

Одно условие

Проверяется одно условие. Команда выполняется только в том случае, если условие истинно.

if (условие)
02

Два варианта

Программа выбирает один из двух путей: условие истинно или условие ложно.

if ... else
03

Несколько вариантов

Можно последовательно проверить несколько условий или выбрать действие с помощью switch.

else if / switch

Примеры использования

01

Проверка возраста

Условие определяет, разрешено ли пользователю выполнить действие.

if (age >= 18) {
    console.log("Разрешено");
}
02

Проверка результата

С помощью if...else можно выбрать один из двух вариантов.

if (score >= 60) {
    console.log("Зачёт");
} else {
    console.log("Незачёт");
}
03

Выбор действия

Конструкция switch подходит для нескольких фиксированных вариантов.

switch (number) {
    case 1:
        console.log("Один");
        break;
    default:
        console.log("Другое");
}

Что такое ветвление?

Ветвление — это управляющая конструкция, которая позволяет программе выбрать дальнейший путь выполнения в зависимости от определённого условия.

Основные конструкции: if, if...else, else if и switch.
